## 实现及真实搜索

默认启动页改为音乐平台搜索，应用仅有音乐搜索、下载记录、视频转 MP3 三个主标签，设置通过右上按钮打开。旧 `main_window.py` 和歌曲目录/人工审核代码保留；MusicBrainz 不参与新入口的必需调用链。当前实际启用的商业音乐目录是 Apple iTunes Search API，未接入它的试听音频、封面或播放器；结果保留指向歌曲商店的按钮。API依据：[Apple 官方文档](https://performance-partners.apple.com/search-api)。约20次/分钟限速，查询缓存24小时，网络调用在后台，可取消。

Windows 原生 GUI 三个样本均真实请求成功，每个请求最多返回30条目录结果：

| 输入 | 返回数 | 歌名、署名歌手完全相符 | 首项时长 | 实际耗时 |
|---|---:|---:|---:|---:|
| 周杰伦 晴天 | 30 | 3 | 269.747 秒 | 5.10 秒 |
| 林俊杰 江南 | 30 | 5 | 267.947 秒 | 1.85 秒 |
| 周传雄 黄昏 | 30 | 4 | 344.2 秒 | 3.32 秒 |

3/3 输入均取得歌名和署名匹配的目录条目。返回列表还含现场、翻唱、其他歌曲；数量不是正确原唱录音数。排名优先歌名、署名一致的条目，已标识的现场/混音/翻奏降低优先级；未知版本不冒称已核实录音室版。仅同平台相同歌曲ID去重，保留发行和版本差异；尚未取得两个已授权平台的跨来源强录音证据，不按标题相似或时长自动归并。

| 平台 | 本轮实际状态 |
|---|---|
| Apple iTunes | 无需密钥，TW目录可访问；实际中文查询成功；仅目录信息/商店链接，未提供本程序完整音频下载许可 |
| Bilibili | 官方开放文档主要列稿件发布/查询；未核实通用自动搜索的适用权限，本轮未请求站内搜索 |
| 网易云、QQ、酷我、酷狗、咪咕 | 未核实本应用可用的公开检索/音频解析授权方式，本轮未请求音乐检索；不能把未请求写成网络不可达或无结果 |
| YouTube | 没有官方 API 密钥，本轮未请求搜索；原有元数据客户端保留 |

## 下载、文件与记录

商店结果点击下载后，以歌曲名/歌手/版本直接调用现有补充来源引擎，再走原 SourceFallbackManager 和 DownloadManager。没有前置 MusicBrainz 选择。Apple目录ID独立保留，不伪造成MusicBrainz Recording；仅标题/歌手/时长相似不通过录音身份核验。因此尚未找到可靠跨来源身份或许可的商业歌曲不会下载，界面显示“暂时没有可下载的音源”。本轮中文真实下载为0，完整中文授权下载验收仍未通过。

## 视频转换

审计前 `ffmpeg` / `yt-dlp` 均未安装，也没有可保留的完整视频转MP3实现。本轮补充独立的本地视频转换，使用QProcess运行FFmpeg、可取消、拒绝覆盖；不关联MusicBrainz。可选依赖 `imageio-ffmpeg` 0.7.0 提供FFmpeg，安装：`python -m pip install -e ".[media]"`。远程视频链接搜索/提取及yt-dlp仍未实现。

真实控制：使用本地产生、可自由使用的2秒黑色视频和正弦音，经原生GUI转换出16,834字节MP3，FFmpeg完整解码退出码0，任务及文件记录已保存，格式/大小/SHA-256/时间/路径可读取。它是生成的工具控制样本，不是中文歌曲或网络下载成功。证据：`.local/reports/final-integration/video-native.json`、`video-native.png`，媒体和数据库均不提交Git。
